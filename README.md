# MU300 / U30 Air 一键刷入 Linux

把 ZTE F50 / MU300 / U30 Air 随身 WiFi 刷成 Linux（OpenWrt 或 Ubuntu），**双击一个文件就行**。

> 本项目只是**封装的启动器**：真正的刷入工作由上游项目
> [dikeckaan/mu300-linux](https://github.com/dikeckaan/mu300-linux) 的官方安装器完成。
> 所有功劳归上游作者；本仓库只做「中文引导 + 环境自检 + 卡住时提示」。
> 刷机有风险，后果自负，与 ZTE / Unisoc 无关。

---

## 一、只需要三步

| 步骤 | 做什么 |
|---|---|
| **1** | 设备**已经 root 并解锁**，用 USB 线插到电脑，**打开 USB 调试** |
| **2** | 下载本仓库（`Code` → `Download ZIP`），解压到任意文件夹 |
| **3** | **双击 `一键刷入.cmd`** |

然后按屏幕提示走。全程约 15 分钟。

> ⚠️ **设备必须已经 root 并且已经解锁**（能启动修改过的 Android boot 镜像）。
> 这一步不在本项目范围内——没 root 的话先去 root，否则装了也起不来。

---

## 二、双击之后会发生什么

一键脚本会按顺序做这些事，每一步都会告诉你在干什么：

```
[1/6] 检查电脑环境（PowerShell / 网络）
[2/6] 检查 adb        ← 没有就自动帮你下载
[3/6] 检查设备连接     ← 没插好会提示你怎么插
[4/6] 检查设备状态     ← 确认设备在 Android，不是 Linux
[5/6] 启动官方安装器    ← 这里开始真正刷入，问几个问题
[6/6] 安装完成提示
```

**第 5 步会问你几个问题**（官方安装器问的，中文界面）：

| 问题 | 怎么选 |
|---|---|
| 语言 | 已经帮你选好中文，不用管 |
| 内部存储还是 SD 卡 | U30 Air 没有卡槽，直接回车；F50 有卡可选卡（更安全） |
| 装哪个系统 | **OpenWrt**（带中文控制面板，推荐）／ Ubuntu ／ 两个都装 |
| 内核 | **7.2**（最新，本机实测可用）／ 6.18 ／ 5.4（最保守） |
| 设密码 | 自己设一个，别忘 |
| 要不要 VPN 模块 | 不需要就选否 |
| 最后确认 | 要**手动输入 `INSTALL`**（大写）才会真的开始写 |

最后一步必须手输 `INSTALL` 是官方设计的安全阀——不输入就什么都不写。

## 三、卡住了怎么办

脚本会盯住每一个阶段。**如果某一步超过预期时间没有动静，它会停下来告诉你现在该做什么**，而不是让你干等。

下面是最常见的几种情况和对应做法：

### ① 卡在「检查 adb」——找不到 adb

一键脚本会尝试自动下载 `platform-tools`。如果自动下载失败，手动来：

1. 打开 https://developer.android.com/tools/releases/platform-tools
2. 下载 **Windows 版**，解压
3. 把解压出的 `platform-tools` 文件夹放到本仓库目录下（和 `一键刷入.cmd` 同级）
4. 重新双击 `一键刷入.cmd`

### ② 卡在「检查设备连接」——`adb devices` 是空的

按顺序排查：

1. **换一根数据线**（很多线只能充电，不能传数据）——这是最常见的原因
2. **换一个 USB 口**，优先插机箱后面的口
3. 设备上是否弹出了「**允许 USB 调试**」的框？**要勾选「一律允许」并点确定**
4. 设备上：设置 → 关于手机 → 连点「版本号」7 次 → 返回 → 开发者选项 → **打开 USB 调试**
5. 仍然没有？在设备的拨号盘/终端里执行 `adb tcpip 5555` 不管用的话，试试重启设备

### ③ 卡在「检查设备状态」——设备当前跑的是 Linux

设备现在开着 Linux，安装器需要它在 **Android** 下才能刷。

**一键脚本会问你是否自动切回 Android**（通过 SSH，需要设备 Linux 的密码）。

如果不能自动切，**手动做**：

```sh
# 用 SSH 连上设备（地址看你是哪种设备）
ssh root@192.168.78.1

# 然后执行
mu300-next-boot android && reboot
```

重启后就回到 Android 了，再重新双击一键刷入。

### ④ 卡在「下载镜像」——进度条不动

GitHub 的下载节点在部分地区会被限速（官方文档实测过 0.2 MB/s）。

- **耐心等**，镜像包总共约 60 MB
- 实在慢：挂个代理，或者设置环境变量换镜像源：
  ```cmd
  set MU300_RELEASE_URL=你的镜像地址
  一键刷入.cmd
  ```

### ⑤ 卡在「下载镜像」——直接报错退出

多半是网络中断。**直接重新双击**即可——官方安装器支持断点续传，已下载的部分不会白下。

### ⑥ 安装器问了一堆问题，我不知道选什么

**全部直接回车**用默认值即可。默认值就是作者推荐的配置。

### ⑦ 提示「空闲空间不足——这似乎是 32 GB 版本」

32GB 版 `userdata` 占满了整块磁盘，需要**缩小 userdata 来腾空间**。

⚠️ **这一步会重写分区表并清空 Android 的全部数据**，而且官方标注为「实验性」。

脚本会要求你先输入 `ERASE` 确认。**在做之前务必先备份**：

```sh
# macOS / Linux，设备在 rooted Android 下
tools/backup-device.sh
```

备份会导出 `prodnv`、调制解调器校准和 IMEI 分区——这些丢了**刷什么固件都救不回来**。

### ⑧ 刷完了，设备没反应

**等两分钟。** 然后拔掉 USB 再插上。

官方设计：连续 5 次启动失败（次数可选 1-6）设备会**自动回到 Android**。所以最坏情况不会变砖。

还是不行的话，收集日志：

```sh
tools/collect-logs.sh
```

### ⑨ 又自己回到 Android 了（用 6.18 内核时）

6.18 内核大约每 20 次启动有 1 次会在最初几秒卡住（上游已知问题 FINDINGS 31m），设备会自动回退到 Android。

**用 7.2 内核可以避免**，或者重新启动 Linux：

```sh
# 设备上（Magisk 模块的 Linux 按钮），或
su -c mu300-linux
```

## 四、刷完之后

等待约 1 分钟，然后在插着设备的电脑上：

```sh
# OpenWrt（推荐，有中文网页面板）
ssh root@192.168.78.1      # U30 Air
ssh root@192.168.77.1      # F50 / MU300

# 或者直接浏览器打开
http://192.168.78.1
```

> U30 Air 是 `192.168.78.1`，F50 / MU300 是 `192.168.77.1`——**很容易记混**。

设备会自己开一个 Wi-Fi 热点，默认用的是从 Android 拷过来的名称和密码。

### 进不去系统？

**忘了密码、Linux 又默认启动**：不需要登录也能救——

1. **回 Android**：设备开机约 10 秒后拔线，反复插拔 5 次（默认失败次数），设备会自己回到 Android
2. **重置密码**（不用启动 Linux）：
   ```sh
   tools/reset-password.sh
   ```
   它会从 Android 挂载 Linux 文件系统、改写密码哈希，**数据全保留**

### 想还原成原样

```sh
./uninstall.sh      # macOS / Linux
.\uninstall.ps1     # Windows
```

## 五、重要警告

- ⚠️ **绝对不要用 OpenWrt 的 `sysupgrade` 或刷 OpenWrt 固件镜像**。那些是给普通电脑写的，会覆盖设备存储。
  普通的 `apk upgrade` 没问题，但**不要**升级 `kernel` 和 `kmod-*` 包。
- ⚠️ **32GB 版本**缩小 userdata 会清空 Android 全部数据，先备份。
- ⚠️ 安装会写入 `boot_b` 和 `misc` 分区（Android 从 b 槽启动时写 `boot_a`）。极端情况下需要 SPD/BROM 工具救砖。
- ⚠️ 不要公开分享包含 IMEI 的备份和日志。

## 六、只想看看不刷机

双击 `一键刷入.cmd` 后，脚本在第 4 步就会告诉你设备状态。想**完全不动设备**地检查：

```cmd
一键刷入.cmd -CheckOnly
```

它只读设备信息、不启动安装器、不写任何东西。

命令行里也可以直接跑 PowerShell 脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\mu300-oneclick.ps1 -CheckOnly
```

## 七、本仓库的文件

| 文件 | 作用 |
|---|---|
| `一键刷入.cmd` | **双击这个**（中文文件名版） |
| `one-click-flash.cmd` | 同一个启动器，ASCII 文件名版（中文名乱码时用这个） |
| `mu300-oneclick.ps1` | 一键脚本主体（中文引导 + 自检 + 卡住提示） |
| `README.md` | 你正在看的教程 |

> `一键刷入.cmd` 和 `one-click-flash.cmd` 内容完全相同，随便用哪个。
> **但不要和 `mu300-oneclick.ps1` 分开**——三个文件必须在同一个文件夹里。

官方安装器会在首次运行时**自动从 GitHub 拉取最新版本**，所以不用手动更新本仓库。
